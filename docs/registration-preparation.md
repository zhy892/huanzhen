# V1.0.0 登记材料准备说明

软件全称：环真牛顿环实验数据分析与还原软件。软件简称：环真。版本：V1.0.0。代码包版本为 `1.0.0`。

## 版本与材料对应

申请材料中的软件名称和版本应与本版本界面、报告、操作说明及源程序一致。制作材料时记录所用 Git 提交号，使用该提交运行并截图，后续变更单独管理。源程序与操作说明不应拼接不同版本。

可使用 `npm run source:manifest` 生成 `artifacts/source-manifest.json`，记录第一方应用源文件的路径、行数和 SHA-256。该清单用于核对文件与排序，不代替源程序交存材料。生成目录默认不纳入版本控制，不包含用户照片、浏览器记录、凭证或依赖源码。

操作说明见 [user-manual.md](user-manual.md)。正式提交前，在同一固定版本补充实际运行截图，覆盖照片输入、图像复核、数据输入、结果报告和实验记录。截图应与文字步骤及按钮名称对应，示例数据应标明。

著作权人、开发方式、完成日期、首次发表情况及权利取得方式由申请人依据实际情况填写。仓库账号、软件显示名称和提交次数不自动证明权利归属。本仓库不代填身份证明、签章或权属证明，也不提供未经核实的作者与开发过程声明。

已发布代码使用 MIT 许可证。保持现有许可证和必要声明，核对第三方代码、字体及素材的使用条件。开发依赖与程序原创部分应区分，依赖源码不作为第一方源程序材料混入。

## 提交前核对

- 从固定提交完成构建、测试及类型检查。
- 核对用户实测读数、参数和报告结果一致，且无预设器材真值与误差提升结论。
- 核对旧记录的计算条件标识，新报告能追溯当轮参数。
- 检查源程序连续性、文件顺序、页码、页眉名称和版本，依据登记机构现行要求排版。
- 对照官方办理指南核对申请表、鉴别材料与权属文件；此说明不代表登记机构受理或授权结论。
