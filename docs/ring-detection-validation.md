# 环纹检测验证

## 测试覆盖

检测器使用确定性的图像与几何算法。测试夹具具有已知椭圆参数，覆盖旋转、偏心、中心环缺失、外环截断、宽暗纹、密集污斑、摩尔纹、RGB 量化及紧取景。夹具用于检查几何恢复，不作为实拍识别准确率的数据集。

正例检查自动选环、中心与半轴误差、轴比偏差和明暗证据；无环纹理及污斑负例不得输出椭圆。原图精化后重新核验明暗支持，避免仅以拟合残差判断结果。

```sh
npm test
```

## 质量门槛

- 保留严格拟合；宽暗纹的点筛选容差由实测纹宽确定，最大为 4.5 个分析图像素。
- 屏幕边框与十字丝不作为环纹观测点。去纹理视图用于定位，接受条件仍由原始分析视图核验。
- 备用暗带搜索有固定的位置、尺寸、轴比和方向范围；初值需要重新提取实测暗纹点并通过检查。
- 明暗核验比例描述有效采样位置的支持程度，不是识别准确率或整圈覆盖率。
- 待复核曲线允许显示模型外推的缺失弧段，但不会因此获得自动数值补偿资格。
- 阈值仍需独立实拍样本验证；受控测试通过不代表任意构图、遮挡或设备都能可靠识别。

## 浏览器回归

`tests/browser/outer-rings.mjs` 将夹具经过上传、颜色转换、成像区定位和原图精化，检查完整页面流程。运行前启动本地服务，并为测试环境安装 Playwright 和 Chromium：

```sh
npm run build
npm start -- --port 3024
# 另一终端，按本机安装位置设置路径
PLAYWRIGHT_MODULE=/path/to/playwright CHROMIUM_PATH=/path/to/chromium node --experimental-strip-types tests/browser/outer-rings.mjs
```

叠图和指标默认保存在系统临时目录的 `huanzhen-ring-browser` 中。浏览器回归验证软件行为，真实计量精度仍需独立人工真值、尺度与重复测量支持。
