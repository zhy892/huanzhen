# 第 13 版原因与算法对应

删除“级次错认与读数操作”诊断条目；将对焦与灰尘合并为“成像清晰度与局部干扰”，保留 8 项原因。十字丝正常存在，少量灰尘常见，不能仅凭这些现象诊断失焦或损坏。先屏蔽检测到的十字丝邻域，剔除孤立点，再检查剩余暗纹证据；只有证据不足时建议复拍。

图像阶段的定位、屏蔽、稳健拟合和留出验证是诊断的共同前置步骤，发生在原因勾选之前。勾选成像或照明项不会重复运行处理，也不会生成额外直径乘数。

新增单一执行计划 `buildRestorationPlan`：诊断页、计算页、结果页、摘要与 CSV 使用同一份原因到算法映射。长度系数仅在勾选标尺比例且系数有效时生效，取消勾选立即回到 1；普通逐差法和稳健回归都使用该受控系数。教学演示也需勾选标尺项，并明确不参与独立物理回归。

透视、镜头畸变、真实偏心量和受力贡献需要独立参数；本次主读数缺少它们时不执行相应数值补偿。执行清单写明缺少的依据，而非因勾选了某个标签就假装调用相应还原公式。受力标定仍在专用面板中针对匹配状态单独计算和报告，不混用照片与读数状态。

执行计划随本轮原始读数保存并纳入 JSON 导出，便于复核实际用过的参数。新增测试检查删除与合并后的原因、未勾选时系数不生效、取消勾选恢复原始结果、缺少独立标定不生成补偿、图像处理不乘入直径及重复选项不重复应用。
