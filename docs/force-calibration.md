# 受力形变标定

入口：主页的“本次实验”记录中展开“受力形变标定 · 条件还原”。

暗环满足 2nt=mλ。使用同一读数方向、同一对暗环，计算有效曲率 K=pλ/[n(r外²−r内²)]。输入半径为毫米、波长为纳米；内部统一 SI 单位。

线性响应 K(q)=a+bq 只在小调整范围适用。至少三个标定状态（含 q=0）拟合 a,b；另有至少一个留出状态验证，目标必须在标定范围内且与模型一致。螺丝转数 q 不是力。多螺丝耦合、滞回和非线性接触不由此模型覆盖。

独立未受力参考半径 Rref 决定共同曲率基准：κF(q)=a+bq−1/Rref。扣除受力间隙贡献后 R=1/(Ktarget−κF)。没有这个独立参考，仅凭多状态照片仍存在共同曲率不可辨识性。单纯相对倾斜主要平移环心；椭圆不能单独证明受力。

标准不确定度输入须来自独立测量评估。程序使用拟合残差、留出最大残差及曲率输入不确定度中的最大值作保守模型项，再合成输入曲率与参考半径项，报告 k=2 的近似扩展不确定度。它不是完整计量预算；尺度、波长、相关读数和接触模型偏差仍需独立评估。验证容差应在测量前确定，不能为了通过而事后放宽。

通过验证后的完整输入随实验保存于浏览器 IndexedDB，并纳入原有 JSON 导出；可重新计算和打印结果。旧实验无此可选字段时保持兼容。自动选环级次未知，不直接用于物理标定；当前需人工跟踪并输入同级环的物理半径。

验证：`node --experimental-strip-types --test tests/force-calibration.test.mjs`，包括已知二次间隙的还原、折射率/单位、缺失独立参考、验证失败、禁止外推及病态分母。
