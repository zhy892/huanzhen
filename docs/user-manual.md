# 环真牛顿环实验数据分析与还原软件 V1.0.0 操作说明

## 1. 用途与运行环境

本软件用于牛顿环实验照片的形状分析、原因排查和用户实测数据的条件还原。用户通过实验仪器完成读数，软件不从照片代替仪器读取直径，也不提供器材真实曲率半径。计算结果取决于输入数据、实验参数、独立标定和物理模型。

使用支持 JavaScript、Canvas 和 IndexedDB 的现代桌面或移动浏览器。照片分析在浏览器本地运行，无需外部分析接口。实验记录存放在当前浏览器，清理浏览器数据可能删除记录；建议通过“输出实验记录”导出 JSON 备份。

## 2. 照片输入与分析

1. 在首页点击“开始分析”；已有实验时可继续本次实验。
2. 选择或拖入 JPG、PNG 等常见格式的照片，单张不超过 12 MB。同一设置下可选择多张照片用于重复性检查。
3. 点击“分析圆环”。系统寻找清晰暗环、追踪暗纹中心线并进行椭圆拟合。
4. 核对叠图是否沿同一暗环。绿色表示有效轮廓点，红色表示被剔除点；虚线中的缺失弧段可能由模型推测，不能视作实测证据。

中心暗斑缺失不必然阻止外侧暗环分析。十字丝和少量灰尘属于常见成像结构，不能单凭这些现象确认失焦或器件损坏。

## 3. 结果复核与原因排查

诊断页显示轴比、轮廓支持、残差及覆盖情况，列出观察方向、受力形变、读数轴偏离、标尺比例、器件损伤、清晰度与局部干扰、照明反光和镜头畸变八类原因。

排查优先级不是故障概率。“可能相关”需现场验证，选中某个原因不会自动证明该原因成立。缺少独立姿态、畸变、偏心或受力标定时，不执行对应的直径数值补偿。需要复测时，使用“按建议调整，重新拍照”，记录实际操作及同时变化的条件。

## 4. 输入实验数据

点击“环真还原”，填写已由仪器测得的各级圆环水平直径，单位为 mm。直径须与记录的级次对应，至少填写六组有效直径。示例数据仅用于熟悉流程，正式结果须替换为实测数据。

核对光源波长、介质折射率和级次差。初始值不代表已识别实验器材。独立长度系数由标准刻尺等独立标定提供；未标定时为 1，且仅在启用对应标尺项时应用。

反射暗环采用 `D² = 4Rλm/n + 截距`。逐差法使用已知级差消除常数间隙项；带自由截距的回归用于交叉复核。单张照片不确定绝对级次。

## 5. 报告与导出

点击“生成还原报告”，查看逐差法曲率估计、全数据回归、长度系数和拟合一致性。展开“稳健回归复核”可查看残差、权重及留出敏感性范围。

使用“复制摘要”“下载 CSV”或“打印报告”输出结果。报告包含软件名称、版本和本次计算参数。器材真实半径未知，不提供相对真值误差或精度提升比例。R² 仅描述拟合一致性；组间离散、不确定度及留出范围不等于相对真值误差，也不能代替完整计量预算。

## 6. 实验记录与受力标定

在“本次实验”或“实验记录”查看轮次、照片、操作和原始读数。新生成的报告保存当轮参数与结果快照；以后修改实验档案，不改变该快照。旧记录未保存计算参数时，界面明确标注重算条件，不能当作原报告复现值。

“受力形变标定”仅用于另有独立未受力参考的实验。输入同一方向、同一对暗环的物理半径，至少三组标定状态及一组留出验证状态，固定相机、尺度与相关条件。缺少独立参考不能据猜测值进行绝对受力补偿，标定结果单独报告。

## 7. 常见提示

| 情况             | 处理方法                                                   |
| ---------------- | ---------------------------------------------------------- |
| 无法支持可靠轮廓 | 核对取景、对焦及可见弧段后复拍                             |
| 图像轮廓待复核   | 检查叠图与原图，先验证目标环，不据此确认器件损坏           |
| 参数或直径无效   | 按提示修改，确认单位、级次及直径递增关系                   |
| 级差未形成逐差组 | 核对填写的级次与级差                                       |
| 多标签页保存冲突 | 刷新并重新打开档案，避免覆盖其他标签页记录                 |
| 无法复制摘要     | 使用 CSV 或打印报告保留结果                                |
| 浏览器存储不可用 | 检查空间和权限，先导出已有记录；更换浏览器不会自动迁移数据 |
