## 统一表述

| 项目 | 本版本的表述 |
| --- | --- |
| 用途 | 牛顿环实验照片的形状分析、原因排查和用户实测数据的条件还原 |
| 读数来源 | 用户通过实验仪器完成直径读数；软件不从照片代替仪器读数 |
| 图像分析 | 在浏览器本地追踪暗纹并拟合环纹，不依赖外部分析接口 |
| 原因排查 | 提供候选因素、图像证据和验证建议；优先级不是故障概率 |
| 曲率结果 | 由实测直径、级次、波长、介质折射率及独立长度标定计算的条件估计 |
| 真实值与精度 | 不预设器材真实半径，不输出相对真值误差或精度提升比例 |
| 拟合指标 | R²、残差和覆盖情况描述模型与数据的一致性，不证明接近真值 |
| 不确定度 | 仅在注明的输入与模型范围内估算，不替代完整计量预算 |
| 受力补偿 | 需独立参考、受控状态与留出验证；结果单独报告 |
| 历史记录 | 新报告保留当轮参数和结果快照；旧记录重算明确标注所用条件 |
