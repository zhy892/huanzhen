# 环真｜牛顿环实验分析工具

面向大学物理牛顿环实验，提供图像拟合、原始读数计算和调整复测记录。

## 使用入口

- `/`：统一实验工作台。首次分析后自动建立实验记录，点击“按建议调整，重新拍照”继续同一次实验，无需再次建档或跳转页面。
- 本次实验：在当前页面查看前后对比、迭代曲线、历史、导出与残余检验；调整说明为选填。单轮可上传最多 8 张同设置照片。
- `/experiment` 为旧地址，自动返回工作台并打开实验记录。

迭代实验流程为：基线记录 → 一项优先建议 → 调整与复测 → 用户确认调整完毕 → 残余检验 → 补偿条件评估。用户可以在任意轮结束，系统不以固定轮数或参考半径决定完成。

## 安装与验证

需要 Node.js 22.13.0 或以上版本。

```bash
npm ci
npm run dev
```

生产构建、测试与类型检查：

```bash
npm test
npm run lint
npx wrangler types .wrangler/runtime.d.ts --config dist/server/wrangler.json --include-env false
npx tsc --noEmit
npm start
```

`npm test` 包含生产构建、服务端页面渲染，以及回归计算、重复性筛查、声明有效性和已移除功能的路由检查。几何回归包含旋转、偏心、窄椭圆、异常点、局部覆盖、相邻环及刻线干扰；这些内部测试不等于真实照片准确率验证。

项目使用 React、vinext、Vite 和 Cloudflare Worker。原托管配置 `.openai/hosting.json` 与构建插件保留；迁移时需核对目标平台绑定。新迭代流程不依赖服务器数据库或远程模型。

单次分析可选 DeepSeek 辅助诊断：服务端配置 `DEEPSEEK_API_KEY`，只发送量化特征，不发送原始照片；未配置时使用本地规则。不要提交密钥。

## 档案保存

照片与记录使用当前浏览器的 IndexedDB 保存，不上传服务器、不自动跨设备同步。浏览器清理、配额不足或设备损坏均可能导致数据丢失，不能视为永久存储。

“导出本次实验”生成包含照片、读数、各轮操作、完成声明和补偿评估的 JSON，用于留存备份。文件导入功能已移除；历史实验直接从浏览器保存的记录继续。打印报告包含全部轮次和声明，退步的轮次不会被删除。

## 计算依据

- 拟合统一使用暗纹中心线：双线性插值、径向极小值亚像素定位与多尺度宽暗纹检测、闭合路径约束，自动比较候选暗环，按质量选择清晰的内侧或外侧条纹，不要求中心或第一级可见。不提供人工取点或点击选环入口。十字刻线按缺失方向处理，不作为环纹观测点。
- 椭圆采用局部坐标归一化、QR 初值、RANSAC 剔除异常点及正半轴参数化的鲁棒距离优化。这里的距离是圆锥曲线的一阶几何距离近似，不宣称精确正交距离求解。
- 先在最长边 900 像素图上粗定位，再从原图裁取目标环区域作精化，精化画布最长边限制为 1800 像素。精化不一致时保留粗定位结果。
- 质量取自实际残差、有效点、弧段覆盖和环周分布，不使用人工取点。环周分布覆盖采用“1−最大角缺口/2π”，用于判断点是否过度集中，不等于每一度都有有效观测；质量评分不是统计正确概率。
- 档案保留椭圆参数及对应分析图尺寸、归一化轮廓点及有效点标记、残差与处理耗时。`ring-v4` 与旧版结果不直接用于干预效果归因，应以新版重新建立基线。
- 闭合追踪失败时，用多个圆心与轴比假设从实际可见暗纹中检验候选椭圆，支持部分被屏幕截断或污斑遮挡的环。机器种子必须与最终椭圆一致，避免搜索外环却退回内环。缺失弧段不伪造观测点。截断或遮挡严重、可辨认弧段不足时提示改善拍摄后重试，不强行输出曲线。
- 自动拟合另以 36 个椭圆角度分区统计“有效弧段覆盖”，与最大角缺口指标同时检查分布。所有拟合使用同一自动质量检查。
- 输出分为可用、待复核、证据不足：待复核时保留橙色候选椭圆和限制说明，禁止自动原因归因及几何补偿；空白或无足够轮廓证据的图片不输出椭圆。旧字段 `damaged` 只表示不宜定量使用，不据此断言仪器损坏。
- 算法阈值为当前工程初值，新增检查覆盖宽暗纹、纹理、截断、遮挡与偏心等受控情形；尚不能用这些检查代替用户原始照片的逐张叠图验证。实拍精度与成功率须以原始照片逐张叠图核验后报告。
- 保存候选环数量、多环轴比与圆心一致性、选择的相对空间范围。绝对级次始终记为未知，不将可见候选顺序冒认为第一级、第二级。中心接触、灰尘与实际读数偏心保持未评估。
- 图像只提供形状证据和待验证原因：单环不能唯一地区分倾斜、透视和横纵比例失真；多环不一致时不使用统一形状解释。站点增强接口与本地诊断应用相同范围限制。
- 不再使用单条环轴比对全部读数做投影/等面积补偿，也不将照片中取景偏移代入弦长公式。数值结果保留原始直径，只有独立长度系数或明确教学标定模式才改变长度。
- 跨轮归因和残余筛查要求自动选环具备多环一致性，且相对空间范围相近；范围变化或缺少复核时只保留曲线，不将换环误判为仪器改善。旧记录保留版本和原始数据，不与新算法直接归因。
- 未实现绝对级次识别、经标定的圆心漂移归因或全图参数反演。
- 新流程的半径计算使用原始直径的 D²–级次带截距回归；共同级次偏移只影响截距，已知级次差必须准确，不按预期答案改动数据。
- 不确定度包含回归散布及直接直径读数的分辨率传播。分辨率按舍入间隔、矩形分布处理，输出 k=2 的条件性扩展不确定度；未包含波长、相关读数及模型失配等全部来源。
- 原单次分析的参考半径修正默认关闭，仅能手动进入明确标注的教学演示。退出演示会重置系数；照片几何经验修正不等于真实误差的唯一还原。

## 残余检验的适用范围

完成一次分析就能查看、导出和输出实验记录，不限制照片数量。“输出实验记录”会展开详细记录并调用浏览器打印，可保存为 PDF。

只有残余误差的统计筛查要求每轮至少 3 张独立有效照片，建议采集 3–5 张；这不会阻止已有记录输出。每次分析均保存为新轮次并加入曲线，重复图片会标记并排除在独立测量统计之外，零波动不作为无误差证据。用最后一轮平均轴比偏离与 Student-t 重复性界限对照；这是形状残余筛查，不涵盖所有系统误差。

该筛查假设重复测量独立、波动近似正态且识别偏差可忽略。历史调整幅度需至少 3 次可比且超过噪声的同类变化才估计，仅作参考，不等于用户能力边界。混杂因素会阻止两轮因果归因。

筛查规则尚未经真实实验标定，不提供正式故障概率或计量认证结论。尚无标注真实照片集支持识别准确率声明。

## 残余补偿

只有当前轮次的有效完成声明、检出的形状残余，以及独立标定依据均满足条件时，才展示条件性长度标定结果。新增轮次会使旧声明失效，必须重新检验。

长度标定按 R'=k²R 及不确定度传播计算，报告补偿前、补偿后、补偿量及条件性不确定度。它不补偿未知的椭圆成因；没有独立标定或存在模型歧义时明确返回不可还原。全图正向拟合、参数可辨识性评估及真实实验阈值标定仍需后续实测验证，当前没有用占位结果代替。
