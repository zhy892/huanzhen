# 环真｜牛顿环实验分析工具

环真用于大学物理牛顿环实验的图像分析和数据复核，支持环纹拟合、实验读数录入、逐差法计算和报告导出。

## 功能

- 从照片提取环纹轮廓，拟合长短轴比、方向与环心偏移；支持手动取点复核。
- 根据图像特征提供仪器调整建议，轮廓质量不足时提示重新拍摄。
- 录入 5、10、15、20、25、30、35、40 级水平直径，计算直径平方、逐差结果、曲率半径和不确定度。
- 导出 CSV、复制结果摘要和打印报告。
- 可选 DeepSeek 辅助诊断；仅发送量化特征，不发送原始照片。未配置密钥或服务不可用时使用本地规则。

## 开发与验证

需要 Node.js **22.13.0 或更高版本**。使用 npm 锁文件安装：

```bash
npm ci
npm run dev
```

访问终端显示的本地地址。其他命令：

```bash
npm test       # 生产构建、页面渲染检查和标定公式回归检查
npm run lint
npm run build
npx wrangler types .wrangler/runtime.d.ts --config dist/server/wrangler.json --include-env false
npx tsc --noEmit
npm start
```

项目使用 React、vinext、Vite 和 Cloudflare Worker。`.openai/hosting.json` 与构建插件是原托管平台的部署配置；迁移部署前应按目标平台调整，不能直接删除后假定仍可部署。数据库目录和 D1 示例为可选扩展，当前实验流程不依赖数据库。

启用远程诊断时，在服务端配置 `DEEPSEEK_API_KEY`，不要把密钥提交到仓库。前端使用者无需填写密钥。

## 计算范围与限制

图像诊断和原因权重属于经验判断，不能作为仪器故障概率或检修结论。当前源码未附用于评估识别准确率的标注照片与测试结果。

程序内置 1.000 m 标准半径，并提供向该参考值进行经验修正的计算。因此，修正后更接近标准值不能作为独立证据证明测量精度提高。使用前须确认参考值适用于实际透镜，实验报告应区分原始读数、经验修正和实际复测结果。

严重畸变、轮廓不完整或疑似元件损坏时，应检查仪器并重新测量。本工具不替代仪器标定。
